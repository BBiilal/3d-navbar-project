# 3d-navbar-project
A visually engaging 3D-inspired navigation bar built with HTML, CSS, and Font Awesome icons. The navbar uses skewed 3D effects and smooth hover animations to create depth and interactivity, enhancing user experience.
Key features:

3D Skew Effect: Achieved using CSS transforms for a dynamic, layered appearance.

Interactive Hover Animation: Menu items move and change color on hover, giving a realistic 3D feel.

Icon Integration: Font Awesome icons added for visual clarity and modern UI aesthetics.

Responsive Design: Centered and adaptable layout for different screen sizes.

This project highlights CSS creativity, animation skills, and the ability to enhance standard navigation elements with engaging, modern UI effects.
